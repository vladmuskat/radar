# Справочник функций и методов

Документ предназначен для последовательного чтения проекта. Он описывает все именованные production-функции и методы; небольшие inline-обработчики React перечислены вместе с родительским компонентом. Тестовые функции сгруппированы по проверяемым инвариантам в конце.

## Rust: ядро симуляции `radar-core`

### `config.rs`

| Функция            | Назначение                                                                                  |
| ------------------ | ------------------------------------------------------------------------------------------- |
| `Config::default`  | Создаёт исходный сценарий: 120 секунд, 12 целей, seed 2401 и стандартные зоны.              |
| `Config::validate` | Проверяет длительность, количество целей, уникальность и геометрию зон до запуска сценария. |

### `geometry.rs`

| Функция             | Назначение                                                                                            |
| ------------------- | ----------------------------------------------------------------------------------------------------- |
| `Point::distance`   | Возвращает расстояние точки от центра РЛС в метрах.                                                   |
| `Point::geographic` | Переводит локальные метры в долготу и широту относительно центра карты.                               |
| `contains`          | Проверяет попадание точки в полигон методом ray casting; граница считается частью зоны.               |
| `is_simple_ring`    | Отклоняет самопересечения, касания, обратные и повторяющиеся рёбра полигона.                          |
| `cross` / `on`      | Внутренние геометрические помощники `is_simple_ring`: ориентация трёх точек и принадлежность отрезку. |

### `zones.rs`

| Функция         | Назначение                                                         |
| --------------- | ------------------------------------------------------------------ |
| `default_zones` | Строит две стандартные зоны обнаружения и одну зону игнорирования. |
| `sector`        | Внутреннее замыкание, аппроксимирующее сектор дугой из 49 точек.   |

### `engine/random.rs`

| Функция           | Назначение                                                         |
| ----------------- | ------------------------------------------------------------------ |
| `Random::unit`    | Генерирует детерминированное число `[0, 1)` алгоритмом xorshift64. |
| `Random::between` | Масштабирует следующее псевдослучайное число в заданный диапазон.  |

### `engine/sweep.rs`

| Функция   | Назначение                                                                      |
| --------- | ------------------------------------------------------------------------------- |
| `bearing` | Вычисляет угол антенны по simulation time; один оборот занимает четыре секунды. |
| `crosses` | Проверяет, пересёк ли луч направление на цель за текущий дискретный шаг.        |

### `engine/generation.rs` и `engine/detection.rs`

| Функция                | Назначение                                                                                                                   |
| ---------------------- | ---------------------------------------------------------------------------------------------------------------------------- |
| `Engine::spawn`        | Создаёт БВС или птицу с допустимыми скоростью, траекторией и временем жизни.                                                 |
| `Engine::visible`      | Проверяет дальность и отсутствие цели внутри зоны игнорирования.                                                             |
| `Engine::update_zones` | Обрабатывает проход луча, обновляет наблюдаемую позицию и след, создаёт уведомления и выполняет запланированное уничтожение. |

### `engine/mod.rs`

| Функция            | Назначение                                                                                              |
| ------------------ | ------------------------------------------------------------------------------------------------------- |
| `Engine::new`      | Валидирует конфигурацию и создаёт готовый, но ещё не запущенный сеанс.                                  |
| `Engine::start`    | Переводит сеанс в `Running`, создаёт начальную популяцию и рассчитывает зоны.                           |
| `Engine::pause`    | Идемпотентно останавливает изменение simulation time и целей.                                           |
| `Engine::resume`   | Возобновляет только ранее приостановленный сеанс.                                                       |
| `Engine::tick`     | Выполняет фиксированный шаг 50 мс: движение, обнаружение, удаление, пополнение и завершение по времени. |
| `Engine::identify` | Валидирует решение оператора, обновляет статистику и планирует удаление цели следующим проходом.        |
| `Engine::finish`   | Однократно завершает сеанс и учитывает оставшиеся пропущенные БВС.                                      |
| `Engine::snapshot` | Формирует безопасный DTO: наблюдаемые координаты без истинного типа и скрытой позиции цели.             |

## Rust: Tauri application layer

### `settings.rs`

| Функция              | Назначение                                                                |
| -------------------- | ------------------------------------------------------------------------- |
| `region`             | Читает встроенный `map-region.json` как типизированные ограничения карты. |
| `Settings::default`  | Возвращает исходные визуальные, звуковые и картографические настройки.    |
| `Settings::validate` | Проверяет громкость, домашнюю позицию и масштаб на Rust-границе.          |
| `Settings::restore`  | Восстанавливает совместимые настройки либо безопасно возвращает defaults. |

### `ports.rs`

`IdentityProvider` определяет `login`, `change_password`, `users` и `set_role`. Это контракт авторизации, который можно реализовать локально или через сервер.

`Repository` определяет `save_training`, `history`, `settings`, `save_settings`, `archive`, `has_archive`, `archives` и `archive_image`. Это контракт долговременного хранения, независимый от SQLite.

### `storage.rs`

| Функция                       | Назначение                                                                                   |
| ----------------------------- | -------------------------------------------------------------------------------------------- |
| `hash`                        | Хеширует пароль Argon2id с уникальной солью.                                                 |
| `verifies`                    | Сверяет пароль с сохранённым Argon2-хешем.                                                   |
| `Store::open`                 | Открывает SQLite, включает WAL/foreign keys, создаёт схему и демонстрационных пользователей. |
| `Store::login`                | Загружает профиль по логину и проверяет пароль.                                              |
| `Store::change_password`      | Проверяет старый пароль и сохраняет новый хеш.                                               |
| `Store::save_training`        | Идемпотентно сохраняет итоговый snapshot по UUID сеанса.                                     |
| `Store::history`              | Возвращает страницу истории и агрегированную статистику всех сеансов пользователя.           |
| `Store::users`                | Возвращает список профилей для административного экрана.                                     |
| `Store::set_role`             | Валидирует и изменяет роль выбранного пользователя.                                          |
| `Store::settings`             | Читает настройки пользователя либо defaults до авторизации.                                  |
| `Store::save_settings`        | Валидирует и атомарно записывает JSON настроек.                                              |
| `Store::archive`              | Декодирует PNG, проверяет лимит и идемпотентно сохраняет снимок события.                     |
| `Store::has_archive`          | Проверяет наличие снимка для пары session/event.                                             |
| `Store::archives`             | Возвращает страницу метаданных архива без тяжёлых PNG-байтов.                                |
| `Store::archive_image`        | Загружает принадлежащий пользователю PNG как data URL.                                       |
| `Store::fail_training_writes` | Только в тестах включает или выключает контролируемую ошибку SQLite.                         |

Реализации `IdentityProvider for Store` и `Repository for Store` делегируют вызовы одноимённым методам `Store`; здесь находится точка замены SQLite другим адаптером.

### `logging.rs`

| Функция          | Назначение                                                                         |
| ---------------- | ---------------------------------------------------------------------------------- |
| `init`           | Создаёт каталог, ежедневный JSONL-файл, console layer, фильтр и panic hook.        |
| `Logging::flush` | Записывает финальное событие и освобождает guard, сбрасывая очередь логов.         |
| `Logging::admit` | Ограничивает frontend-ошибки двадцатью событиями в секунду.                        |
| `Frame::safe`    | Пропускает только ограниченные имена JS/TS-файлов и координаты кода.               |
| `frontend_log`   | Принимает от UI enum-категории и безопасные stack frames без произвольных payload. |

### `main.rs`

| Функция                         | Назначение                                                                                   |
| ------------------------------- | -------------------------------------------------------------------------------------------- |
| `Command::name`                 | Возвращает безопасное имя команды для логов, не сериализуя пароли и аргументы.               |
| `close_application`             | Перед закрытием окна завершает и надёжно сохраняет активный сеанс.                           |
| `request`                       | Передаёт одну IPC-команду worker-потоку и ждёт ответ с timeout.                              |
| `subscribe`                     | Подключает Tauri Channel для последовательных снимков состояния.                             |
| `Worker::new`                   | Собирает application service из движка, репозитория и провайдера идентичности.               |
| `Worker::require_archive_saved` | Запрещает смену сеанса, пока PNG ещё не записан.                                             |
| `Worker::packet`                | Объединяет snapshot и возможную ошибку сохранения.                                           |
| `Worker::require_user`          | Защищает команды, требующие входа.                                                           |
| `Worker::require_session`       | Отклоняет запоздавшие команды от предыдущего UUID сеанса.                                    |
| `Worker::save_finished`         | Идемпотентно сохраняет завершённую тренировку и удерживает ошибку для повторной попытки.     |
| `Worker::handle`                | Оборачивает команду таймингом, структурными логами и логированием перехода состояния.        |
| `Worker::handle_inner`          | Реализует маршрутизацию всех команд, права, границы сеанса и порядок долговременных записей. |
| `Worker::publish`               | Отправляет актуальный пакет подписчику; при потере WebView ставит тренировку на паузу.       |
| `Worker::run`                   | Владеет движком в одном потоке, обслуживает команды и выполняет ticks с периодом 50 мс.      |
| `main`                          | Настраивает Tauri, логирование, SQLite, worker, IPC handlers и безопасное закрытие окна.     |

## TypeScript: транспорт, состояние и утилиты

### `api.ts`

| Функция           | Назначение                                                                            |

### `persistence.ts`

| Функция                    | Назначение                                                                         |

| `Preferences::constructor` | Создаёт последовательную очередь записи настроек.                                  |

| `PendingCapture::flush`    | Ждёт текущую операцию и повторяет сохранение тех же байтов после ошибки.           |

### `settings-validation.ts` и `training-view.ts`

| Функция              | Назначение                                                                               |

## TypeScript: React-компоненты

### `App.tsx`

| Функция              | Назначение                                                                                     |
| -------------------- | ---------------------------------------------------------------------------------------------- |
| `App`                | Корневой orchestrator UI: авторизация, сеанс, диалоги, настройки, архив, звук и зоны.          |
| `restorePreferences` | Синхронно обновляет очередь, ref и React state проверенными настройками.                       |
| `ensureAudio`        | Лениво создаёт/возобновляет AudioContext после пользовательского жеста.                        |
| `accept`             | Принимает только актуальные последовательные snapshots нужного session ID.                     |
| `connect`            | Создаёт новое поколение подписки и игнорирует callbacks устаревшего канала.                    |
| `transition`         | Ставит движок на паузу, сбрасывает PNG/настройки и только затем меняет сеанс или пользователя. |
| `perform`            | Унифицирует busy-counter и отображение ошибки одной команды.                                   |
| `action`             | Выполняет start/pause/resume/finish/reset с нужной подготовкой и приёмом snapshot.             |
| `run`                | Внутренняя операция `action`, отправляющая session-scoped команду.                             |
| `login`              | Обрабатывает форму, загружает профиль/настройки и подключает snapshot-channel.                 |
| `logout`             | Подтверждает активный сеанс, дожидается записей и очищает локальное состояние.                 |
| `start`              | Валидирует переход, создаёт новый UUID-сеанс и запускает его подтверждённой конфигурацией.     |
| `identify`           | Отправляет решение по цели только активному, не заблокированному сеансу.                       |
| `saveSettings`       | Оптимистично обновляет UI через последовательную очередь и сообщает об ошибке записи.          |
| `openProfile`        | Загружает выбранную страницу истории перед открытием профиля.                                  |
| `openSettings`       | Для администратора дополнительно загружает пользователей.                                      |
| `openArchive`        | Загружает страницу архива без PNG и сбрасывает ранее открытое изображение.                     |
| `addZone`            | Собирает polygon, проверяет его в Rust и защищается от ответа, пришедшего в новый сеанс.       |

Эффекты `App` выполняют bootstrap/часы, обработку системного закрытия, показ результатов, очистку кратких сообщений и реакцию на новые уведомления. Последний эффект воспроизводит звук и запускает защищённый захват PNG с группировкой пять секунд.

### `RadarMap.tsx`

| Функция    | Назначение                                                                              |
| ---------- | --------------------------------------------------------------------------------------- |
| `RadarMap` | Создаёт MapLibre-карту, все radar layers, обработчики целей, pinned-карточки и cleanup. |
| `set`      | Внутренне обновляет GeoJSON-source по имени.                                            |
| `animate`  | На каждом новом `observedAtMs` меняет feature-state для короткой пульсации отметки.     |
| `radial`   | Строит конец луча длиной семь километров для заданного угла.                            |

Эффекты карты отдельно синхронизируют snapshot/луч/следы, удаляют карточки исчезнувших целей, обновляют зоны и черновик полигона. Одинарный click закрепляет карточку, double click планирует уничтожение.

## Утилиты подготовки карты

| Функция                                   | Назначение                                                            |
| ----------------------------------------- | --------------------------------------------------------------------- |
| `LinuxPath` в `prepare-map.ps1`           | Переводит Windows-путь в путь выбранного WSL distribution.            |
| `parts` в `prepare_map.py`                | Рекурсивно разворачивает geometry collections нужной размерности.     |
| `ocean_polygons`                          | Восстанавливает море по направленным OSM coastline и границе региона. |
| `classify`                                | Раскладывает OSM feature по MVT-слоям и типам.                        |
| `generate`                                | Валидирует, обрезает и записывает GeoJSON-слои и manifest с SHA-256.  |
| `tileX` / `tileY` в `build-map-tiles.mjs` | Переводят географические координаты в номера XYZ-тайлов.              |
| `tileX` / `tileY` в `check-map.mjs`       | Вычисляют ожидаемое покрытие при проверке manifest.                   |

`build-map-tiles.mjs` выполняет верхнеуровневый pipeline GeoJSON → MVT, а `check-map.mjs` — проверку файлов, хешей, покрытия и обязательных слоёв.

## Тестовые функции

- `crates/radar-core/src/engine/tests.rs`: пауза, детерминизм, параметры генерации, граница птиц, их время жизни, отложенное уничтожение, зоны, геометрия, прямой полёт БВС и обновление только лучом.
- `crates/radar-core/tests/public_contract.rs`: поведение через публичный API, включая экзамен и идемпотентный finish.
- `crates/radar-core/tests/map_region.rs`: совпадение Rust-центра и покрытия локальной карты.
- `src-tauri/src/*` под `cfg(test)`: лог-файл, настройки, SQLite, права, сохранение, архив и оконное закрытие.
- `tests/*.test.mjs`: frontend-логирование, очереди настроек/PNG и runtime-валидация.
- `scripts/map/test_prepare_map.py`: направление береговой линии, острова, разрывы и polygon holes.
