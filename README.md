# РАДАР — тренажёр оператора РЛС

Локальное Windows-приложение на **Rust + TypeScript + Tauri 2**. Интерфейс ориентирован на предоставленные скриншоты: карта, кольца дальности, одинаковые отметки целей, зоны, уведомления, пауза и результаты.

## Запуск

Требуются Node.js 22+, Rust stable MSVC (проверено на 1.95), WebView2 Runtime и компоненты Visual Studio: C++ x64/x86 build tools и Windows 11 SDK. Проект не требует ключей API, интернета во время работы или внешнего сервера.

```powershell
npm ci
npm run desktop
```

Демонстрационные учётные записи (создаются при первом запуске):

| Логин      | Пароль     | Роль          |
| ---------- | ---------- | ------------- |
| `operator` | `operator` | Оператор      |
| `admin`    | `admin`    | Администратор |

Пароли в SQLite хешируются Argon2id. Изменённый пароль сохраняется; следующий запуск не возвращает демонстрационный пароль. Это локальная учебная авторизация, не граница защиты от владельца компьютера.

`npm run dev` открывает только UI-предпросмотр для разработки: Rust-команды в обычном браузере недоступны. Отдельная веб-версия продукта не поставляется.

## Release-сборка

На новом компьютере сначала установите зафиксированные npm-зависимости, затем запустите production-сборку:

```powershell
npm ci
npm run desktop:build
```

Готовый исполняемый файл:

```text
target\release\radar-trainer.exe
```

Его можно запустить напрямую:

```powershell
.\target\release\radar-trainer.exe
```

`scripts/desktop.ps1` автоматически подключает среду Visual Studio через `vswhere`, если она не настроена в текущем терминале. Команда использует `tauri build --no-bundle`, поэтому создаёт standalone `.exe` без MSI-установщика и цифровой подписи.

## Пользовательский сценарий

1. Войти как `operator`.
2. При необходимости открыть «Зоны наблюдения» и нарисовать полигон щелчками по карте.
3. Нажать «Начать тренировку», выбрать длительность, число целей и номер сценария.
4. Один раз нажать на точку, чтобы закрепить рядом карточку скорости и координат; повторный щелчок закрывает её. Двойной щелчок отмечает предполагаемое БВС и планирует уничтожение: цель остаётся на экране до следующего прохода луча.
   Луч делает оборот за 4 секунды: при каждом проходе отметка обновляется и пульсирует. Жирные белые линии показывают историю обнаружений. В настройках можно включить направление движения (по умолчанию выключено): стрелка оценивается по двум последним обнаружениям, не по скрытой физике цели.
5. Нажать «Пауза»: цели, генерация и время остановятся; навигация карты останется доступна.
6. Продолжить тренировку или завершить её кнопкой с квадратом. Посмотреть результаты и историю в профиле.

В экзамене правильность ответов скрыта до завершения. В тренировке текущая статистика доступна слева. Повторная отметка одной цели не засчитывается. Сброс и выход сохраняют текущий результат, если тренировка уже началась.

## Соответствие параметрам ТЗ

| Параметр            | БВС                     | Птицы                  |
| ------------------- | ----------------------- | ---------------------- |
| Скорость            | 25–35 м/с (90–126 км/ч) | 2–10 м/с (7,2–36 км/ч) |
| Траектория          | Прямая к РЛС            | Плавно меняющийся курс |
| Стартовая дальность | 3,1–6,9 км              | 0,3–6,8 км             |
| Срок жизни модели   | 30–80 с                 | 5–20 с                 |

На карте до 20 объектов одновременно. Птицы плавно разворачиваются у границы радиуса и через 5–20 секунд заменяются новой целью, поэтому со временем не вытесняют БВС. Зоны игнорирования временно скрывают объекты. БВС могут покинуть область наблюдения или исчезнуть по окончании срока жизни. Сроки жизни целей, соотношение типов 50/50 при генерации и пределы настройки длительности 30–3600 с — решения прототипа в рамках требований; ЧТЗ не предоставлено.

## Локальные данные

SQLite находится в каталоге данных приложения Tauri: `%APPDATA%/ru.radar.trainer/radar.sqlite3`. Там хранятся пользователи, настройки, история тренировок и PNG-снимки событий. Исходники и Git не содержат эти пользовательские данные.

Снимки рабочего пространства сохраняются группами: не чаще одного раза в 5 секунд, до 30 за сеанс. Снимок привязан к событию и содержит состояние UI на момент захвата, а не исторический пересчёт точного тика. Удаление уведомлений очищает только текущий список, архив сохраняется. Политика длительного хранения архива пока не реализована.

# Логирование и диагностика

Основа та же, что в Wallet/logger: `tracing`, `tracing-subscriber`, `tracing-appender`. Wallet не изменён и не является зависимостью RADAR. Для desktop не нужны сервер логов, Docker или отдельный микросервис.

## Где смотреть

Windows: `%LOCALAPPDATA%\ru.radar.trainer\logs`, обычно `C:\Users\vladm\AppData\Local\ru.radar.trainer\logs`. Путь определяет Tauri `app_log_dir()`, фактическое значение записывается при запуске. Файл `radar.YYYY-MM-DD.jsonl`: каждая строка — JSON, время UTC.

```powershell
$radarLogDir = Join-Path $env:LOCALAPPDATA 'ru.radar.trainer\logs'
Get-ChildItem -LiteralPath $radarLogDir
$radarLatestLog = Get-ChildItem -LiteralPath $radarLogDir -Filter 'radar.*.jsonl' |
  Sort-Object LastWriteTime -Descending | Select-Object -First 1
Get-Content -LiteralPath $radarLatestLog.FullName -Tail 50 -Wait
```

Также журнал выводится в консоль при `npm run desktop`. По умолчанию свои события — INFO, сторонние библиотеки — WARN. Для подробного начала/завершения команд:

```powershell
$env:RUST_LOG = 'warn,radar_trainer=debug'
npm run desktop
# После диагностики:
Remove-Item Env:RUST_LOG
```
